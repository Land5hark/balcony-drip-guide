## Publishing checklist (when deploy resumes)

1. Verify live URLs work: `curl -s https://balcony-drip-guide.pages.dev/posts/...`
2. Submit sitemap to Google Search Console
3. Post Pinterest pins (1 per day for 5 days)
4. Post Twitter thread + pin reply
5. Post Reddit variations (stagger by 2-3 days per subreddit)
6. Add UTM parameters to URLs for tracking:
   - Pinterest: `?utm_source=pinterest&utm_medium=social&utm_campaign=tomato-drip`
   - Twitter: `?utm_source=twitter&utm_medium=social&utm_campaign=herb-drip`
   - Reddit: `?utm_source=reddit&utm_medium=social&utm_campaign=tomato-drip`
