## Channel rules worth obeying

### X
Use the sharpest contrarian lines mostly intact.

Best fit:
- one-liner pain-point hooks
- strong binary endings
- buyer/problem-aware article links

Avoid:
- stacking multiple links in one post
- sounding like a catalog
- posting three near-duplicate lines for the same article back to back

Recommended structure:
1. hook line
2. live article URL
3. optional short clarifier only if needed

### Pinterest
Pinterest wants clearer utility and less “internet knife fight” energy.

Best fit:
- concrete problem framing
- list-style promises
- “best for” or “how to” phrasing
- image title overlays derived from the article promise

Adaptation rule:
- soften the sarcasm
- keep the practical contrast
- turn binary conflict into visual curiosity

Recommended structure:
- pin title
- 1-sentence description
- destination URL
- image text overlay matching search intent

### Reddit-safe reuse
Reddit punishes obvious promotion, so the safest move is to adapt article insights into experience-shaped comments or text posts only where they truly fit.

Best fit:
- “here’s what actually caused my uneven watering” style framing
- comparison summaries without affiliate stink
- troubleshooting sequences

Avoid:
- dropping naked links as the whole contribution
- acting like a brand account
- posting in communities where balcony/container gardening isn’t the actual topic

Recommended structure:
1. plain-English observation
2. short practical framework or checklist
3. only then mention the fuller write-up if context allows

## Practical posting sequence

Do not spray everything at once like a maniac.

Use this rotation:
1. X tests one lane at a time for 3-5 posts across a week
2. Pinterest gets utility-first versions from the same lane in parallel
3. Reddit-safe reuse happens only when a live thread genuinely matches the problem

Recommended first sequence:
1. Lane A first — easiest broad pain point
2. Lane C second — strongest troubleshooting trust builder
3. Lane B third — strongest buyer-intent cleanup lane

## Reuse rule

For each live article, keep three versions ready:
- sharp X hook
- softened Pinterest utility headline
- plain-English Reddit-safe summary

That prevents rewriting from scratch every time and makes the asset library actually compound.
