# Balcony Drip Irrigation Promotion Execution Log Template

Purpose: give the posting workflow somewhere to land once real distribution starts.

Without this, the queue is just neat paperwork and nobody learns which hooks actually pull.

## How to use it

For each real promotion attempt, log:
- date
- channel
- article
- hook/title used
- post URL if one exists
- whether it was original post, pin, or Reddit-safe reuse
- early result notes
- whether the angle should be reused, revised, or killed

## Suggested first logging buckets

### Lane A — no-faucet + solar decision traffic
Track whether these outperform:
- no-spigot pain
- weak-sun reality check
- reservoir math vs plant-count bluff

### Lane B — timer / accessory / expansion buyer traffic
Track whether these outperform:
- smart-timer skepticism
- accessory anti-sludge angle
- expansion-regret hook

### Lane C — emitter / troubleshooting / micro-layout traffic
Track whether these outperform:
- partial-clog diagnosis
- mixed pots vs repeatable pots
- hanging-basket / rail-planter geometry pain

---

## Weekly review questions

At the end of a real posting week, answer:
1. Which lane got the cleanest response?
2. Which hook got attention but weak click intent?
3. Which article earned the best trust-building response?
4. Which angle sounded clever but didn’t actually move anything?
5. What should be reused next week?
6. What should be retired without ceremony?

---

## Minimal rule

Do not trust memory.
Log the exact copy and outcome while it is still fresh.
Otherwise this turns into the usual fake-content-marketing folklore machine and that shit is useless.
