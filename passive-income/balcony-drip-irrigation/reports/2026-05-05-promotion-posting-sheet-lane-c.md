## Reddit-safe lane summary

Use this only where the conversation already fits and the problem is real.

### Summary angle 1
Mixed pots and repeatable pots usually want different emitter logic. Adjustable emitters help when the garden is messy; fixed drippers usually make more sense when the layout is stable and repetitive.

### Summary angle 2
If one pot keeps losing while the timer looks fine, I’d suspect a partial clog before I started stretching runtime. Comparing that emitter against a healthy one usually exposes the lie fast.

### Summary angle 3
Hanging baskets and rail planters usually fail from coverage and placement, not from a lack of timer features. One dripper at one end of a rail planter is how people accidentally build their own troubleshooting hobby.
