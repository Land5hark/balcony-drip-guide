Nano Tank ATO Reliability is a small content site focused on one thing: helping aquarium hobbyists avoid dumb, expensive, or stressful auto-top-off mistakes in nano and open-top tanks.

The site is built around practical guidance, including:

- troubleshooting repeated overfill behavior
- understanding common failure modes
- comparing sensor and system tradeoffs
- thinking more carefully about reservoir size, maintenance burden, and real-world setup risk

This is not meant to be a hype machine.

The goal is to publish useful guidance that helps people make safer and more informed decisions, especially in smaller systems where a minor top-off mistake can turn into a bigger problem fast.

## How recommendations are approached
When products are mentioned, the standard is:

- fit before commission
- caution before certainty
- real tradeoffs over generic "best product" fluff
- honest verification status when product-level details still need more checking

## What this site is not
This site is not trying to cover every aquarium topic under the sun. It is intentionally narrow so the guidance can stay practical, specific, and useful.

If the site expands later, it should still stay close to the same core idea: reliability-first aquarium equipment guidance for small systems.
